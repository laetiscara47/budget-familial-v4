MON BUDGET FAMILIAL — VERSION 12.1 COMPTES

Améliorations principales :
- ajout, modification et suppression de comptes ;
- choix du type, de la couleur et de l’icône ;
- définition du compte principal ;
- modification directe du solde actuel, même si des opérations existent ;
- conservation automatique de l’historique des opérations.

Installation : remplacez les fichiers de votre dépôt par ceux de ce dossier, puis faites un commit et un push.
Après publication, rechargez avec Ctrl + F5.
